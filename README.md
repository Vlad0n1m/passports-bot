# Passports Bot

Telegram-бот для заполнения таблиц экипажа по фото документов моряков (паспорт, УЛМ).
Распознаёт документы через LLM (OpenRouter) и выгружает готовую таблицу в Google Sheets.

## Как работает

1. Пользователь нажимает «🆕 Новая таблица» — начинается сессия.
2. Отправляет фото документов моряка (можно несколько: страницы паспорта, УЛМ, альбомом или по одному).
3. Бот показывает, какие поля заполнены (✅), а какие не нашёл (❌). Можно дослать фото — данные дополнятся.
4. «➡️ Следующий паспорт» — сохраняет моряка и переходит к следующему.
5. «🔄 Сбросить текущего моряка» — стирает данные только текущего моряка
   (например, если замешалось чужое фото); ранее сохранённые моряки не трогаются.
6. «✅ Завершить» — бот создаёт лист в Google Sheets и присылает прямую ссылку.
   «❌ Отменить всё» — полностью отменяет сессию.

На каждого моряка в таблице одна строка; внутри ячеек данные разделены переносами строк:
ФИО латиницей + кириллицей, дата рождения + гражданство, загранпаспорт + УЛМ.
Колонка «Должность» остаётся пустой — заполняется вручную.

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env  # и заполнить значения
python -m bot.main
```

## Настройка Google Sheets

1. Зайдите в [Google Cloud Console](https://console.cloud.google.com/), создайте проект (или используйте существующий).
2. Включите API: **Google Sheets API** и **Google Drive API** (APIs & Services → Enable APIs).
3. Создайте сервисный аккаунт (IAM & Admin → Service Accounts → Create), роль можно не назначать.
4. Во вкладке Keys сервисного аккаунта создайте JSON-ключ и сохраните его как `service_account.json` в корне проекта (или укажите путь в `GOOGLE_SERVICE_ACCOUNT_FILE`).

Дальше два режима (выбирается через `.env`):

- **`GOOGLE_SPREADSHEET_ID` задан (рекомендуется)** — бот добавляет новый лист в вашу
  существующую таблицу и присылает ссылку сразу на этот лист. Для этого создайте
  Google-таблицу и дайте сервисному аккаунту (email вида
  `...@...iam.gserviceaccount.com` из JSON-ключа) доступ «Редактор». ID таблицы — это
  часть URL между `/d/` и `/edit`.
- **`GOOGLE_SPREADSHEET_ID` не задан** — бот пытается создавать новую Google-таблицу на
  каждую сессию. ⚠️ У сервисных аккаунтов Google нулевая квота Drive, поэтому этот режим
  обычно падает с ошибкой «storage quota has been exceeded» — используйте первый режим.

## Переменные окружения

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | Токен Telegram-бота от @BotFather |
| `OPENROUTER_API_KEY` | API-ключ OpenRouter |
| `OPENROUTER_MODEL` | Модель с поддержкой изображений (по умолчанию `google/gemini-2.5-flash`) |
| `GOOGLE_SERVICE_ACCOUNT_FILE` | Путь к JSON-ключу сервисного аккаунта |
| `GOOGLE_SPREADSHEET_ID` | (Необязательно) ID существующей таблицы для добавления листов |
